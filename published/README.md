# Published Records

This directory stores internal publication records, not necessarily the canonical article body.

For each published story, create a record using the story ID with:

- public URL;
- publication timestamp;
- modification timestamp;
- final headline;
- source research dossier;
- fact-check record;
- corrections/updates;
- data assets used;
- distribution notes;
- measured outcomes when available.

Do not duplicate the public website's entire content store here unless deliberately chosen later.
