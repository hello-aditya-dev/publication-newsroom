# Workflow — WRITE

## Goal

Produce a technically precise draft from research—not from memory or generic web summaries.

## Inputs

- approved story;
- research dossier;
- analysis;
- relevant style/editorial policies.

## Before writing

Answer:
1. What is the single most important supported insight?
2. What does the reader already probably know?
3. What evidence must appear early?
4. What information gain distinguishes this article?
5. What uncertainty must remain visible?

## Draft procedure

1. Choose format appropriate to the evidence.
2. Draft headline candidates without overstating.
3. Write a dek that adds information.
4. Lead with the consequential supported point.
5. Present evidence before expansive interpretation.
6. Use tables where comparison dimensions are consistent.
7. Preserve vendor-claim attribution.
8. State calculation assumptions.
9. Include unknowns when material.
10. Specify visuals/data separately rather than inventing illustrations.

## Quality test

Delete or rewrite any paragraph that:
- merely restates the headline;
- contains unsupported hype;
- could fit almost any technology announcement;
- repeats another paragraph;
- explains basic concepts the target reader doesn't need;
- obscures who is making a claim.

## Output

Create/update:
`drafts/YYYY-MM-DD-slug.md`

The draft is not approved for publication.
