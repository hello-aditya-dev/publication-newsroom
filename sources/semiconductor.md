## Evidence checklist for hardware stories

Capture:
- exact SKU/product;
- architecture;
- process node only if officially stated or strongly sourced;
- memory capacity/type;
- memory bandwidth;
- interconnect;
- supported precisions;
- power envelope;
- form factor/rack architecture;
- software stack/version;
- availability window;
- price only when actually disclosed;
- benchmark conditions.

## Caution

Roadmaps slip. "Sampling", "production", "shipping", "available", and "generally available" are
not interchangeable.
