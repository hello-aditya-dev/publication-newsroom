# AI Labs — Starter Source Registry

**Purpose:** Primary sources for model releases, research, system cards, API changes, and technical
announcements.

Verify URLs when first used and record the specific source page in each research dossier.

| Organization | Primary surfaces | Typical use |
|---|---|---|
| OpenAI | https://openai.com/news/ ; https://openai.com/research/ ; https://platform.openai.com/docs/ | releases, research, API/docs |
| Anthropic | https://www.anthropic.com/news ; https://docs.anthropic.com/ | releases, research, API/docs |
| Google DeepMind | https://deepmind.google/discover/blog/ ; https://deepmind.google/research/ | research, model/system announcements |
| Google AI / Gemini | https://blog.google/technology/ai/ ; https://ai.google.dev/ | product/model releases, developer docs |
| Meta AI | https://ai.meta.com/blog/ ; https://ai.meta.com/research/ | open model/research announcements |
| Mistral AI | https://mistral.ai/news/ ; https://docs.mistral.ai/ | model releases, API/docs |
| xAI | https://x.ai/news ; https://docs.x.ai/ | model/product updates, docs |
| Hugging Face | https://huggingface.co/blog | open-model ecosystem and technical releases |

## High-value artifacts to look for

- system/model cards;
- API pricing pages;
- changelogs;
- technical reports;
- benchmark methodology;
- context limits;
- rate limits;
- release notes;
- open weights/licenses;
- GitHub repositories linked by the originating team.

## Caution

A lab is authoritative about what it released and what it claims. It is not independent evidence
that its model is the "best", "safest", "fastest", or "most capable" in general.
